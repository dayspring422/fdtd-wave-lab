# FDTD Wave Lab

An interactive 2D simulation of electromagnetic waves, built by solving Maxwell's equations directly on a grid with the finite-difference time-domain (FDTD) method. You can run preset experiments (double slit, refraction, a lens, an optical fiber, a phased antenna array, a Faraday cage) or build your own by placing sources and drawing conductors and glass.

**Live demo: https://dayspring422.github.io/fdtd-wave-lab/**

## Running it

Open `index.html` in a browser. Nothing needs to be installed or built.

In VS Code, the Live Server extension also works: right-click `index.html` and choose "Open with Live Server", and the page reloads whenever you save a file.

The tests need Node.js:

```
node tests/stability.js     # every preset stays numerically stable (a few seconds)
node tests/validate.js      # numerical validation, writes VALIDATION.md (about a minute)
```

## Project layout

```
index.html          page structure and controls
style.css           layout and colors (light and dark themes)
js/solver.js        the physics: Yee grid, field updates, absorbing boundary, sources
js/measure.js       measures angles and wave speeds from the simulated field
js/presets.js       the ready-made experiments
js/render.js        turns the field values into an image
js/main.js          connects the controls to the solver
tests/stability.js  runs each preset without a browser and checks the fields stay bounded
tests/validate.js   compares measured results with theory and writes VALIDATION.md
```

All of the physics lives in `js/solver.js`. The other files handle measurement, presets, drawing, and the interface.

## The physics

The simulation uses the TMz mode: the electric field points out of the screen (Ez) and the magnetic field lies in the plane (Hx, Hy). Maxwell's curl equations then reduce to

```
dEz/dt =  (1/eps) (dHy/dx - dHx/dy)
dHx/dt = -(1/mu)   dEz/dy
dHy/dt =  (1/mu)   dEz/dx
```

The Yee scheme stores E and H on grids offset by half a cell, and updates them half a time step apart. Every derivative becomes a centered difference between neighboring cells, so each time step is a pass of H updates followed by a pass of E updates.

- **Stability.** The Courant number S = c dt/dx is 0.5. In 2D the scheme is stable only for S ≤ 1/√2; above that the fields grow without bound.
- **Materials.** Glass has relative permittivity εr = n², which slows waves to c/n. A perfect conductor forces Ez = 0, which reflects waves completely.
- **Boundaries.** A 20-cell perfectly matched layer (PML) surrounds the visible region. Ez is split into two parts, Ez = Ezx + Ezy, so waves moving in x and in y can be damped separately (Berenger's split-field formulation). The loss grows as the cube of depth into the layer, and the electric and magnetic losses are matched so the layer does not reflect in the continuous equations. An older graded-loss layer, which damps all components equally, is kept for comparison and can be selected in the interface.
- **Sources.** Sources are "soft": they add a sine wave to Ez instead of overwriting it, so reflected waves pass through them. A line source with a phase that varies along its length produces a tilted plane wave.

## Measuring from the field

Once the simulation reaches steady state, every cell oscillates as Ez(t) = Re{A e^(iωt)}. The code extracts the complex amplitude A at every cell by summing Ez(t) e^(−iωt) over exactly one period, like a lock-in amplifier. For a plane wave A ∝ e^(−ik·r), so the phase difference between neighboring cells gives the wavevector k: its direction is the propagation angle and ω/|k| is the phase velocity.

The refraction preset uses this live. It shows the transmitted angle and the wave speed in the glass as measured from the field, next to Snell's law and c/n, with the percentage difference. Snell's law appears nowhere in the solver.

## Validation

Full results are in [VALIDATION.md](VALIDATION.md), regenerated by `node tests/validate.js`. In summary:

- **Wave speed.** Measured phase velocity agrees with the Yee scheme's dispersion relation at every resolution. The error against the exact speed falls from 2.0% at 8 cells per wavelength to 0.09% at 24 in vacuum, and from 5.8% to 0.48% in glass, about second order.
- **Refraction.** The measured transmitted angle matches the Yee prediction to within 0.1%. Its difference from Snell's law falls from 4.9% to 0.6% as the grid goes from 8 to 24 cells per wavelength, again about second order. The remaining difference is numerical dispersion in the glass.
- **Absorbing boundary.** A pulse test against a large reference domain gives reflection of −103 dB head-on and −99 dB at a corner for the PML, against −40 dB and −34 dB for the graded-loss layer with the same loss profile.

## Publishing the demo

The site is static, so GitHub Pages can serve it directly: in the repository go to Settings → Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, and save. The `.nojekyll` file tells Pages to serve the files as they are.

## Ideas for extending it

- Add the TE mode (Hz out of the screen, with Ex and Ey in the plane).
- Add lossy materials with conductivity σ and measure the skin depth.
- Add a dispersive material (Drude or Lorentz model) so the refractive index depends on frequency.
- Measure the reflection coefficient at the glass interface and compare it with the Fresnel equations.
